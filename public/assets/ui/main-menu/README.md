# Main Menu Assets

Expected PNG:

- `background.png` — full-screen background for the Deckborn main menu and Play screen.

Keep the central area readable so the logo and menu controls remain clear.

## Main menu buttons

The main screen uses image-backed buttons when these files exist:

- `buttons/play.png` — artwork for the **Play** button.
- `buttons/decks.png` — artwork for the **Build Decks** button.

The PNGs can contain the complete button artwork, including their text. If an image is missing, the frontend automatically falls back to a basic text button.
